JavaLens

JavaLens is a network packet sniffer that's built in Java using Pcap4J and JavaFX. Designed for learners and network enthusiasts like myself. It gives you a real-time look at your network traffic with a clean UI and cross-platform support.

Easily monitor TCP/UDP packets, filter protocols, and visualize live stats — all in a beginner-friendly interface.
